# Security Policy

## Supported versions

Only the latest release and the current `master` branch receive security fixes.

## Reporting a vulnerability

SpaceSage deletes files, so bugs like unintended data loss, bypassed safety checks or
privilege problems are treated as security issues.

1. **Do not open a public issue.**
2. Report it privately through
   [GitHub private vulnerability reporting](https://github.com/emirkefi/spacesage/security/advisories/new)
   (the "Report a vulnerability" button on the repository's Security tab).
3. Include what happened, how to reproduce it and the impact you see.

You can expect an acknowledgement within a few days. Once a fix is released, you will be
credited in the release notes unless you prefer to stay anonymous.
