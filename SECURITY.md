# Security Policy

## Supported Versions
Only the latest release and the current `main` branch are actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
Because `arch-disk-tui` performs low-level disk operations, potential vulnerabilities (e.g., unintended data loss, improper permission elevation) are taken seriously.

1. **Do not open a public issue.**
2. Report vulnerabilities privately via [GitHub Private Vulnerability Reporting](https://github.com) on this repository, or contact the maintainer directly.
3. Include details of the vulnerability, steps to reproduce, and potential impact.
